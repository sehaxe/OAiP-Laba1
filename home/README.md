## Задача 1

**Ввести катеты прямоугольного треугольника. Найти его гипотенузу и площадь.
Результат вывести с точностью до двух знаков после запятой.**

### Решение

```c
#include <stdio.h>
#include <math.h>

//Задача 1. Вариант 5

int main(void) {
    float a, b;

    printf("Введите катеты прямоугольного треугольника "
           "(через пробел, enter не имеет значения)\n");

    if (scanf("%f %f", &a, &b) != 2 || a <= 0 || b <= 0){
        printf("Ошибка ввода!\n");
        return 1;
    }

    printf("Гипотенуза: %.2f\n", sqrt(a * a + b * b));

    printf("Площадь: %.2f\n", a * b / 2);

    return 0;
}
```

Разберём, что тут происходит.

В первых двух строках подключаются стандартные библиотеки: stdio — стандартный
ввод и вывод, math — набор математических функций, отсюда берётся sqrt.

```c
#include <stdio.h>
#include <math.h>
```

Дальше основная функция **main()**. Почему она объявлена с типом int, ведь
сама функция не является числом? Ответ чуть позже, а пока про то, что написано
в скобках:

```c
int main(void) {
```

Слово void означает, что функция не принимает параметров. Функции в Си можно
переиспользовать: одни функции вызывают другие, например так:

```c
int sum(int a, int b) {
    return a + b;
}

int main(void) {
    int result = sum(3, 5);

    printf("%d", result);
    return 0;
}
```

Здесь функция **sum** переиспользована для сложения двух чисел, и так можно
поступать с чем угодно. Так вот, main(void) означает лишь отсутствие
параметров, к переиспользованию это отношения не имеет: void в скобках —
защита от дурака, запрещающая передавать main аргументы. То же относится
и к любой другой функции: сумматор без параметров выглядел бы так:

```c
int sum(void) {
    return 3 + 5;
}

int main(void) {
    int result = sum();

    printf("%d", result);
    return 0;
}
```

Такая функция всегда возвращала бы 3 + 5, потому что не принимает параметры.
Если попытаться передать ей аргументы, компилятор сообщит об ошибке.

Теперь про int. Для main стандартный возвращаемый тип — int, потому что
функция возвращает операционной системе код завершения программы. Для других
функций можно использовать и float с double.

```c
int main(void) {
    int result = sum(3, 5);

    printf("%d", result);
    return 0;
}
```

Из примера выше видно, что int — целое число, а return 0; в конце означает,
что функция вернула операционной системе ноль. В программистской среде
договорились: 0 — всё прошло без ошибок, ненулевое значение — что-то не так
(конкретный смысл числа зависит от программы). Поэтому в основном коде есть
такая секция:

```c
if (scanf("%f %f", &a, &b) != 2 || a <= 0 || b <= 0){
        printf("Ошибка ввода!\n");
        return 1;
    }
```

Условие if проверяет, что scanf прочитал ровно два значения и оба катета
положительные. За «прочитал ровно два» отвечает часть:

```c
!= 2
```

**!=** значит «не равно», то есть что угодно, кроме 2.

```c
||
```

Логическое **ИЛИ**: условие сработает, если выполняется хотя бы одна его часть.

```c
&&
```

Для справки — логическое **И**: дальше выполнение пойдёт, только если соблюдены
оба условия сразу.

```c
a <= 0 || b <= 0
```

Эти два условия проверяют, что a не меньше или равно нулю и то же для b,
между ними знакомое **||** (ИЛИ) — достаточно одной ошибки. Если хоть одно
условие выполнилось, программа выводит сообщение об ошибке и завершается:

```c
return 1;
```

Возвращаем единицу — код ошибки, о котором говорили выше.

Кстати, про **void** (с англ. «пустота»). Если написать:

```c
void main(void) {
```

то функция не будет возвращать вообще ничего: ни 0, ни 1.

```c
printf("Гипотенуза: %.2f\n", sqrt(a * a + b * b));
```

Строка вывода гипотенузы. Сначала считается квадратный корень через **sqrt**,
потом результат подставляется вместо

```c
%.2f
```

.2 означает «два знака после запятой», а %f в целом — что сюда попадёт число
с плавающей точкой.

```c
printf("Площадь: %.2f\n", a * b / 2);
```

С площадью то же самое, только без корня. После этого программа завершается
и возвращает 0.

## Задача 2

**Ввести шестизначный номер билета и определить, счастливый ли он. Билет
называется счастливым, если сумма первых трёх его цифр равна сумме трёх
последних.**

### Решение

```c
#include <stdio.h>

//Задача 2. Вариант 5

int main(void) {
    int a, b, c;

    printf("Введите номер билета\n");

    if (scanf("%d", &a) != 1 || a < 100000 || a > 999999){
        printf("Ошибка ввода!\n");
        return 1;
    }

    b = a / 100000 + a / 10000 % 10 + a / 1000 %10;

    c = a % 10 + a / 10 % 10 + a / 100 % 10;

    if (b == c) {
        printf("БИЛЕТ СЧАСТЛИВЫЙ!!! (✿^‿^)\n");
    } else {
        printf("Вам не повезло (｡ŏ﹏ŏ)\n");
    }

    return 0;
}
```

Проверка ввода здесь по накатанной схеме из первой задачи, залипать на ней
не будем. Отличие только в условии:

```c
a < 100000 || a > 999999
```

Любой шестизначный номер лежит в диапазоне от 100000 до 999999, поэтому если
число вышло за эти границы, пользователь ввёл не шесть цифр, и программа
честно ругается. Кстати, именно поэтому билет вида 012312 в неё не засунуть:
для компьютера это просто число 12312, и проверку оно не пройдёт.

Самое интересное здесь — как достать по одной цифре из большого числа.
Понадобятся две новые вещи: целочисленное деление и остаток от деления.

```c
b = a / 100000 + a / 10000 % 10 + a / 1000 %10;
```

Когда делим друг на друга два int, дробная часть у результата отбрасывается.
Например 123321 / 100000 — это 1, а не 1.23321, потому что int не умеет хранить
дроби. Так получена первая цифра номера.

Оператор **%** — остаток от деления: 7 % 3 это 1, потому что 7 = 3 * 2 и
остаётся единица. А дальше фокус: **остаток от деления числа на 10 всегда равен
его последней цифре**, например 123 % 10 — это 3.

Смотрим, как это работает вместе: a / 10000 сначала отбрасывает две последние
цифры (от билета остаётся 1233), затем % 10 забирает последнюю цифру этого
числа (3), и это уже третья цифра исходного номера. Точно так же a / 1000 % 10
даёт третью цифру с начала. В сумме b собираются первые три цифры номера.

```c
c = a % 10 + a / 10 % 10 + a / 100 % 10;
```

С последними тремя цифрами даже проще, потому что они уже с краю: a % 10 —
последняя цифра, a / 10 % 10 — предпоследняя, a / 100 % 10 — третья с конца.
Две суммы собраны.

```c
if (b == c) {
```

Сравниваем их через **==**. Важно не путать его с **=**: одиночное равно —
присваивание, двойное — проверка равенства. Суммы сошлись — билет счастливый,
не сошлись — не счастливый.

## Задача 3

**Определить, какие из заданных трёх действительных чисел a, b и c являются
целыми.**

### Решение

```c
#include <stdio.h>
#include <math.h>

//Задача 3. Вариант 5

int main(void) {
    float a, b, c;

    printf("Введите три числа\n");

    if (scanf("%f %f %f", &a, &b, &c) != 3){
        printf("Ошибка ввода!\n");
        return 1;
    }

    if (fmodf(a, 1) == 0) {
        // не (int)a потому что int может переполниться при
        // конвертации слишком большого числа из float, а fmodf
        // ничего не конвертирует и float оставляет исходным, а
        // выражение fmodf(a, 1) == 0 буквально остаток от
        // деления на 1 равен нулю
        printf("Число 1 является целым!\n");
    }
    if (fmodf(b, 1) == 0) {
        printf("Число 2 является целым!\n");
    }
    if (fmodf(c, 1) == 0) {
        printf("Число 3 является целым!\n");
    }
    if (fmodf(a, 1) != 0 && fmodf(b, 1) != 0 && fmodf(c, 1) != 0){
        printf("Ни одно из чисел не является целым(\n");
    }

    return 0;
}
```

Ввод и проверка «ровно три числа» — снова по накатанной схеме. А главный
вопрос задачи интересный: как вообще выяснить, что дробное число целое?

Помогает функция **fmodf** из знакомой по первой задаче библиотеки math.h:

```c
if (fmodf(a, 1) == 0) {
```

Во второй задаче мы уже видели остаток от деления и оператор **%**, но у него
принципиальное ограничение: он работает только с целыми int. Здесь числа
дробные, нужна версия остатка для float — это fmodf. Она возвращает остаток
от деления первого числа на второе, а остаток от деления на 1 — просто
дробная часть числа: 5.0 делится на 1 без остатка, у 3.7 останется 0.7.
Критерий получается простой: **если число делится на 1 без остатка, оно
целое**. Именно поэтому результат сравнивается с нулём.

Кстати, прямо в коде оставлен комментарий, почему не использовано приведение
типа, хотя проверка a == (int)a тоже напрашивалась: при таком превращении
дробная часть отбрасывается и равенство ломается на любом дробном числе,
но только пока число помещается в int. У int потолок примерно два миллиарда:
скормить программе число побольше — при конвертации случится переполнение.
fmodf же ничего никуда не конвертирует, всё вычисление остаётся в мире float,
и такие числа ему не страшны.

Дальше посмотрите на структуру: три проверки написаны тремя отдельными if,
безо всяких else между ними.

```c
if (fmodf(b, 1) == 0) {
```

Это принципиально. По заданию нужно определить, какие ИЗ чисел целые, то есть
отчитаться о каждом. Лесенка if - else if остановилась бы на первом целом
числе и про остальные промолчала, а независимые if проверяют все три числа
всегда.

Остался последний случай: а если целых нет ни одного? Для этого после трёх
проверок стоит четвёртая:

```c
if (fmodf(a, 1) != 0 && fmodf(b, 1) != 0 && fmodf(c, 1) != 0){
```

Читается буквально: если a не целое, И b не целое, И c не целое — целых нет,
и программа сообщает об этом. Обратите внимание: проверки здесь с != 0,
а не с == 0, ведь мы ищем числа, у которых дробная часть есть; связаны они
знакомым по первой задаче логическим **И**.

После этого программа возвращает 0 и завершается.

## Задача 4

**Вывести меню выбора времени года (1 это зима, 2 это весна, 3 это лето,
4 это осень), принять номер от пользователя и напечатать месяцы выбранного
сезона.**

### Решение

```c
#include <stdio.h>

//Задача 4. Вариант 5

int main(void){

    int status;

    printf("Введите время года\n");
    printf("1.Зима\n");
    printf("2.Весна\n");
    printf("3.Лето\n");
    printf("4.Осень\n");

    if (scanf("%d", &status) != 1 || status <= 0 || status >= 5){
        printf("ТЫ НЕ ПРОЙДЕШЬ!!!!\n");
        return 1;
    }

    switch (status) {
        case 1:
            printf("Декабрь, Январь, Февраль\n");
            break;
        case 2:
            printf("Март, Апрель, Май\n");
            break;
        case 3:
            printf("Июнь, Июль, Август\n");
            break;
        case 4:
            printf("Сентябрь, Октябрь, Ноябрь\n");
            break;
        default:
            printf("Как ты сюда попал, но это очень впечатляет\n");
    }

    return 0;

}
```

Начнём с простого: меню — это четыре printf подряд, ничего хитрого. А дальше
новая конструкция — **switch**.

```c
switch (status) {
```

Она придумана ровно для таких случаев, когда одна переменная может принять
несколько конкретных значений, и на каждое значение хочется отреагировать
по-своему. Можно было бы соорудить лесенку if - else if, как в третьей задаче,
но switch делает то же сильно аккуратнее.

```c
case 1:
```

Работает так: берём значение из скобок (у нас это status) и ищем среди case
число, которое с ним совпало. Совпало — выполняем всё от этого case до
ближайшего **break**. Break здесь критично важен: он говорит программе, что
нужное найдено и можно выходить. Забудешь его — программа провалится вниз
и начнёт выполнять следующий case, потом следующий, и так до конца или до
первого встреченного break. Только представьте: ввели зиму, а вам напечатали
все четыре сезона разом.

```c
default:
```

default — запасной вариант на случай, если ни один case не подошёл. Правда,
ситуация тут забавная: проверка ввода выше уже не пустила ничего, кроме чисел
от 1 до 4, поэтому до default выполнение дойти не может. Он здесь как
подстраховка у канатоходца: по идее не нужна, но спокойнее.

Ну и после switch программа возвращает 0 и завершается, всё по классике.
