## Задача 1

**Ввести катеты прямоугольного треугольника. Найти его гипотенузу и площадь. Результат вывести с точностью до двух знаков после запятой.**

### Вот как выглядит решение 1 задачи:

```c
#include <stdio.h>
#include <math.h>

//Задача 1. Вариант 5

int main(void) {
    float a,b;

    printf("Введите катеты прямоугольного треугольника "
           "(через пробел, enter не имеет значения)\n");

    if (scanf("%f %f", &a, &b) != 2 || a <= 0 || b <= 0){
        printf("Ошибка ввода!\n");
        return 1;
    }

    printf("Гипотенуза: %.2f\n", sqrt(a * a + b * b));

    printf("Площадь: %.2f\n", a * b / 2);

    return 0;
}
```

Давайте разберем что было тут сделано.

В первый двух строках мы подключили 2 стандартные библиотеки (stdio - стандартный ввод и вывод, а также math - просто набор расширенных математических функций)

```c
#include <stdio.h>
#include <math.h>
```

Далее начинаем создание нашей основной функции **main()**.
У вас мог возникнуть вопрос почему мы создаём её с типом int, ведь сама функция не является числом. И вы будите правы, но на этот вопрос я отвечу чуть посже а пока хочу обратить ваше внимание на то что в main написано в скобках

```c
int main(void) {
```

Слово void означает что функция не принемает никаких параметров (Тоесть сама по себе функция потому что в коде их можно переиспользывать и одни функции могут вызывать другие по типу такого примера)


```c
int sum(int a, int b) {
    return a + b;
}

int main(void) {
    int result = sum(3, 5);

    printf("%d", result);
    return 0;
}
```

Тоесть как вы могли заметить мы переиспользовали функцию **sum** чтобы посчитать наши числа и так можно делать с чем угодно и main(void) означает, что функция main не принимает параметров. Это не связано с запретом переиспользования функции: void в скобках только показывает отсутствие параметров (типо как защита от дурака), но также это касаеться и не главной функции тоесть например наш сумматор если бы не принимал параметров и был бы написан например так

```c
int sum(void) {
    return 3 + 5;
}

int main(void) {
    int result = sum();

    printf("%d", result);
    return 0;
}
```

Такая функция всегда возвращала бы 3 + 5, потому что она вообще не принимает параметры. Если попытаться передать ей параметры, компилятор сообщит об ошибке.

почему главная функция имеет тип int, а не float или double. Для main стандартным является возвращаемый тип int, потому что функция возвращает операционной системе код завершения программы. Для других функций float и double использовать можно.

```c
int main(void) {
    int result = sum(3, 5);

    printf("%d", result);
    return 0;
}
```

Из прошлого примера мы видим, что int - это целое число, а return 0; в конце означает, что функция возвращает операционной системе число 0 после завершения работы. в программисткой среде принят консенсус что число 0 значит что все прошло без ошибок а 1 как показатель что что то не так (ненулевые значения обозначают ошибку, а конкретный смысл числа может зависеть от программы). И именно поэтому в основном коде есть такая секция

```c
if (scanf("%f %f", &a, &b) != 2 || a <= 0 || b <= 0){
        printf("Ошибка ввода!\n");
        return 1;
    }
```

Условие if проверяет, что scanf успешно прочитал не ровно два значения. Об этом говорит часть:

```c
!= 2
```

**!=** это значит не равно тоесть что угодно в нашем случае кроме 2.

```c
||
```
если выполняется это условие или любое следующее, то выполняется то, что написано дальше.

```c
&&
```
Для справки это просто логическое **И**. тоесть если соблюдаеться это **И** это условие то только тогда выполни что дальше.

```c
a <= 0 || b <= 0
```

эти два условия проверяют, что число a меньше или равно нулю или что число b также меньше или равно нулю, а между ними уже нам знакомый **||** (ИЛИ) чтобы проверить хотя бы одно ошибочное условие. Если выполняется хотя бы одно из них, программа выводит сообщение об ошибке.

```c
return 1;
```
И уже в конце всего **return 1;** если проверка обнаружила, что хотя бы одно число меньше или равно нулю или было успешно введено не два числа,

Также раз уже заговорили про **main(void)** не могу не сказать про тип **void** (с англ. пустота) например

```c
void main(void) {
```

Это значит что наша функция ничего не возвращает ни 1 ни 0 вообще ничего.

```c
printf("Гипотенуза: %.2f\n", sqrt(a * a + b * b));
```

Вот строка вывода гипотенузы. В ней сначала выполняется расчёт через **sqrt** - функцию квадратного корня, после чего результат подставляется вместо

```c
%.2f
```

.2 означает что я хочу видеть только 2 знака после запятой а в целом %f то что я подрузамеваю что это будет число с плавающей точкой

```c
printf("Площадь: %.2f\n", a * b / 2);
```

И в целом тоже самое только без корня. После чего программа успешно заверщаеться возращая 0 если все прошло без ошибок.

## Задача 2

**Ввести шестизначный номер билета и определить, счастливый ли он. Билет называется счастливым, если сумма первых трёх его цифр равна сумме трёх последних.**

### Вот как выглядит решение 2 задачи:

```c
#include <stdio.h>

//Задача 2. Вариант 5

int main(void) {
    int a, b, c;

    printf("Введите номер билета\n");

    if (scanf("%d", &a) != 1 || a < 100000 || a > 999999){
        printf("Ошибка ввода!\n");
        return 1;
    }

    b = a / 100000 + a / 10000 % 10 + a / 1000 %10;

    c = a % 10 + a / 10 % 10 + a / 100 % 10;

    if (b == c) {
        printf("БИЛЕТ СЧАСТЛИВЫЙ!!! (✿^‿^)\n");
    } else {
        printf("Вам не повезло (｡ŏ﹏ŏ)\n");
    }

    return 0;
}
```

Давайте разберем что было тут сделано.

С проверкой ввода тут всё по накатанной схеме из первой задачи, так что залипать на ней не будем. Отличие только в условии

```c
a < 100000 || a > 999999
```

Любой шестизначный номер лежит в диапазоне от 100000 до 999999, поэтому если число выбралось за эти границы, значит пользователь ввёл не шесть цифр, и программа честно ругается. Кстати именно поэтому билет вида 012312 в неё не засунуть: для компьютера это просто число 12312, и проверку оно не пройдёт.

А самое интересное тут это то, как мы достаём по одной цифре из большого числа. Для этого встречаются сразу две новые вещи: целочисленное деление и остаток от деления.

```c
b = a / 100000 + a / 10000 % 10 + a / 1000 %10;
```

Когда мы делим друг на друга два int, дробная часть у результата просто отбрасывается. Например 123321 / 100000 это 1, а не 1.23321, потому что int не умеет хранить дроби. Так мы получили первую цифру номера.

Оператор **%** это остаток от деления: 7 % 3 это 1, потому что 7 = 3 * 2 и остаётся единичка. И тут начинается магия: **остаток от деления числа на 10 всегда равен его последней цифре**, например 123 % 10 это 3.

Смотрим как это работает вместе: a / 10000 сначала отбрасывает две последние цифры (от нашего билета остаётся 1233), а потом % 10 забирает у этого числа последнюю цифру (3), и вот это уже третья цифра исходного номера. Точно так же a / 1000 % 10 даёт третью цифру с начала. В сумме b складываются первые три цифры номера.

```c
c = a % 10 + a / 10 % 10 + a / 100 % 10;
```

С последними тремя цифрами даже проще, потому что они уже с краю: a % 10 это последняя цифра, a / 10 % 10 предпоследняя, а a / 100 % 10 третья с конца. Всё, две суммы собраны.

```c
if (b == c) {
```

Ну и в конце сравниваем их через **==**. Тут важно не путать его с **=**, потому что это разные вещи: одиночное равно это присваивание, а двойное это проверка равенства. Суммы сошлись, значит билет счастливый, а не сошлись, значит не сошлись.

## Задача 3

**Определить, какие из заданных трёх действительных чисел a, b и c являются целыми.**

### Вот как выглядит решение 3 задачи:

```c
#include <stdio.h>
#include <math.h>

//Задача 3. Вариант 5

int main(void) {
    float a, b, c;

    printf("Введите три числа\n");

    if (scanf("%f %f %f", &a, &b, &c) != 3){
        printf("Ошибка ввода!\n");
        return 1;
    }

    if (fmodf(a, 1) == 0) {
        // не (int)a потому что int может переполниться при
        // конвертации слишком большого числа из float, а fmodf
        // ничего не конвертирует и float оставляет исходным, а
        // выражение fmodf(a, 1) == 0 буквально остаток от
        // деления на 1 равен нулю
        printf("Число 1 является целым!\n");
    }
    if (fmodf(b, 1) == 0) {
        printf("Число 2 является целым!\n");
    }
    if (fmodf(c, 1) == 0) {
        printf("Число 3 является целым!\n");
    }
    if (fmodf(a, 1) != 0 && fmodf(b, 1) != 0 && fmodf(c, 1) != 0){
        printf("Ни одно из чисел не является целым(\n");
    }

    return 0;
}
```

Давайте разберем что было тут сделано.

С вводом и проверкой, что введено ровно три числа, тут всё по накатанной схеме из прошлых задач, так что залипать не будем. А вот главный вопрос задачи звучит интересно: как вообще выяснить, что дробное число является целым?

Тут нам поможет функция **fmodf** из уже знакомой нам по первой задаче библиотеки math.h:

```c
if (fmodf(a, 1) == 0) {
```

Во второй задаче мы уже знакомились с остатком от деления и оператором **%**, но у него есть принципиальное ограничение: он работает только с целыми int. А тут числа дробные, поэтому нам нужна версия остатка для float, и это как раз fmodf. Она возвращает остаток от деления первого числа на второе, и остаток от деления на 1 это просто дробная часть числа: 5.0 делится на 1 без остатка, а у 3.7 останется 0.7. Из этого получается простой и красивый критерий: **если число делится на 1 без остатка, оно целое**. Именно поэтому результат сравнивается с нулём.

Кстати, прямо в коде оставлен комментарий с объяснением, почему тут не использовано приведение типа, ведь проверка a == (int)a тоже напрашивалась: при таком превращении дробная часть отбрасывается, и равенство действительно ломается на дробных числах, но только пока число помещается в int. У int потолок примерно два миллиарда, и если скормить программе число побольше, при конвертации произойдёт переполнение. fmodf же ничего никуда не конвертирует и всё вычисление остаётся в мире float, так что ему такие числа не страшны.

Дальше обратите внимание на структуру: три проверки написаны тремя отдельными if, безо всяких else между ними.

```c
if (fmodf(b, 1) == 0) {
```

Это принципиально. По заданию нужно определить, какие ИЗ чисел целые, то есть отчитаться про каждое. Лесенка if - else if останавливалась бы на первом целом числе и про остальные молчала, а независимые if проверяют все три числа всегда, кто бы из них ни оказался целым.

Ну и остался последний случай: а если целых не оказалось ни одного? Для этого после трёх проверок стоит четвёртая:

```c
if (fmodf(a, 1) != 0 && fmodf(b, 1) != 0 && fmodf(c, 1) != 0){
```

Читается она буквально: если a не целое, И b не целое, И c не целое, значит ни одного целого числа нет, и программа сообщает об этом. Обратите внимание, что проверки тут с != 0, а не == 0, ведь мы ищем числа, у которых дробная часть есть, и связываем их знакомым нам по первой задаче логическим **И**.

После этого программа возвращает 0 и успешно завершается.

## Задача 4

**Вывести меню выбора времени года (1 это зима, 2 это весна, 3 это лето, 4 это осень), принять номер от пользователя и напечатать месяцы выбранного сезона.**

### Вот как выглядит решение 4 задачи:

```c
#include <stdio.h>

//Задача 4. Вариант 5

int main(void){

    int status;

    printf("Введите время года\n");
    printf("1.Зима\n");
    printf("2.Весна\n");
    printf("3.Лето\n");
    printf("4.Осень\n");

    if (scanf("%d", &status) != 1 || status <= 0 || status >= 5){
        printf("ТЫ НЕ ПРОЙДЕШЬ!!!!\n");
        return 1;
    }

    switch (status) {
        case 1:
            printf("Декабрь, Январь, Февраль\n");
            break;
        case 2:
            printf("Март, Апрель, Май\n");
            break;
        case 3:
            printf("Июнь, Июль, Август\n");
            break;
        case 4:
            printf("Сентябрь, Октябрь, Ноябрь\n");
            break;
        default:
            printf("Как ты сюда попал, но это очень впечатляет\n");
    }

    return 0;

}
```

Давайте разберем что было тут сделано.

Начнём с простого: меню это просто четыре printf подряд, ничего хитрого. А вот дальше появилась новая конструкция, и зовут её **switch**.

```c
switch (status) {
```

Она придумана ровно для таких случаев, когда одна переменная может принять несколько конкретных значений, и на каждое значение хочется отреагировать по-своему. Можно было бы, конечно, соорудить лесенку if - else if как в третьей задаче, но switch делает это сильно красивее.

```c
case 1:
```

Работает так: берём значение из скобок (у нас это status) и ищем среди case то число, которое с ним совпало. Совпало, значит выполняем всё, что написано после этого case и до ближайшего **break**. Break тут критически важен: он говорит программе, что нашли что искали и можно выходить. Если его забыть, программа не остановится, а провалится вниз и начнёт выполнять следующий case, потом следующий, и так до конца или до первого встреченного break. Только представьте: ввели зиму, а вам напечатали все четыре сезона разом.

```c
default:
```

default это запасной вариант на случай, если ни один case не подошёл. Правда у нас тут забавная ситуация: проверка ввода выше уже не пустила ничего, кроме чисел от 1 до 4, поэтому до default выполнение дойти не может никак. Он здесь как подстраховка у канатоходца: по идее не нужна, но спокойнее.

Ну и после switch программа возвращает 0 и завершается, всё по классике.
