# ghostflow

Блок-схемы по ГОСТ из простого текста. Пишешь схему почти как markdown —
получаешь готовую картинку, вписанную в A4 вертикально (165×247 мм).

Один файл, одна зависимость: `matplotlib`.

## Формат схемы

Построчный, порядок строк = порядок блоков сверху вниз.
«начало» и «конец» добавляются автоматически.

```text
# комментарий
ввод scanf("%d", &a)              # параллелограмм (ввод)
b = a / 100000 + ...              # прямоугольник (действие);
                                  # строка без ключевого слова тоже действие
вывод printf("Гипотенуза...")     # параллелограмм (вывод)
если a < 100000 || a > 999999     # ромб; ниже ветки с отступом (4 пробела)
    да -> конец: printf("Ошибка..."); return 1   # ветка уходит в конец
вывод printf("Площадь...")        # основной поток продолжается ниже

если switch (status)              # веток может быть сколько угодно
    1: printf("Декабрь...")
    2: printf("Март...")
    иначе: printf("Как ты сюда попал...")
```

Правила:

- `ввод текст` и `вывод текст` — параллелограмм; остальное — прямоугольник.
- `если условие` — ромб; условие автоматически оформляется как `if (...)`
  (если уже начинается с `if`/`switch` — остаётся как есть).
- Ветки пишутся с отступом 4 пробела в виде `метка: текст`.
  Одна плитка на ветку. Пустой текст (`нет:`) — просто подпись
  на основной линии.
- `метка -> конец: текст` или `текст -> конец` — ветка уходит напрямую
  в «конец», минуя основной поток.
- Длинные подписи можно сокращать и заканчивать троеточием.

## Использование

```bash
python ghostflow.py схема.txt результат.png
```

или из python:

```python
import ghostflow
ghostflow.render(open("схема.txt").read(), "результат.png")
```

Примеры схем — в папке `examples/`.

## Стиль (по ГОСТ, без настройки)

- начало/конец — прямоугольник со скруглёнными краями;
- ввод/вывод — параллелограмм;
- действие — прямоугольник;
- условие — ромб с `if (...)` или `switch (...)`;
- все линии строго ортогональны (углы 90°), стрелки из вершин фигур;
- фигуры одного типа имеют одинаковый размер в пределах схемы.
