# ОАиП — Лабораторная работа №1

**Структура программы на Си. Функции ввода-вывода** (БГУИР, вариант 5).
Четыре задачи на Си: линейные программы, проверка ввода, ветвления и `switch`.

## Структура проекта

```
1/ … 4/        задачи: main.c (код) + scheme.png (блок-схема, генерируется из кода)
report/        отчёт: main.typ (исходник), main.pdf (готовый), assets/ (скриншоты)
template/      общий шаблон отчёта (титульник, типографика, подписи)
Makefile       сборка программ, отчёта и схем
```

## Сборка

Все команды — из папки `home/`.

**Программы** (нужен gcc):

```bash
make            # соберёт 1/main … 4/main
./1/main        # запуск задачи 1
make clean
```

**Отчёт** (нужен [Typst](https://typst.app/open-source/)):

```bash
make report     # -> report/main.pdf
```

Исходник отчёта — `report/main.typ`, оформление подключается из
`template/oaip.typ` (титульный лист, шрифты, нумерация рисунков и листингов
ставятся сами). Листинги программ читаются напрямую из `1/main.c … 4/main.c`.

## Блок-схемы — gostpadi

Схемы не рисуются руками: их генерирует утилита
**[gostpadi](https://github.com/sehaxe/gostpadi)** — один python-файл,
по ГОСТ 19.701-90 (все линии под 90° и одной толщины, фигуры одного типа
одного размера, при нехватке места схема сама делится на листы соединителями
«А», «Б»).

Взять её можно тремя способами — от простого к полноценному:

```bash
# 1. вообще без установки: запуск прямо с GitHub (нужны uv и интернет)
uv run https://raw.githubusercontent.com/sehaxe/gostpadi/main/gostpadi.py схема.gvn

# 2. как одноразовый инструмент
uv run --with matplotlib https://github.com/sehaxe/gostpadi/raw/main/gostpadi.py ...

# 3. клонировать репозиторий и пользоваться локально
git clone https://github.com/sehaxe/gostpadi && cd gostpadi
python gostpadi.py схема.gvn
```

В папке каждой задачи лежит `scheme.png` — схема, сгенерированная прямо из
`main.c`. Перегенерировать все: `make schemes`. Посмотреть/получить текст
схемы, если захочется поправить:

```bash
gostpadi 1/main.c --labels=ru --show     # картинка сразу в терминал
gostpadi 1/main.c --labels=ru --gvn      # вывести текст схемы (.gvn)
```

Подробности формата и все опции — в README репозитория gostpadi.

## Терминальные скриншоты

Скриншоты результатов (`report/assets/term_task*.png`) генерируются из
реальных запусков программ: `report/make_screens.py` прогоняет каждую задачу
и собирает Typst-файл в стиле терминала (если фактический вывод разошёлся
с ожидаемым — генерация падает, чтобы скриншоты не врали).
